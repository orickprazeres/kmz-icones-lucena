# kmz-icones-lucena

Ícones e legendas usados nos KMZ das obras (Google Earth Pro).
Só imagens genéricas — sem coordenadas, valores ou dados de contrato.

- `icones/` — 1 PNG por tipo de serviço (grupos do orçamento) + variantes com anel de status (`_liberada`, `_pendente`, `_bloqueada`).
- `legendas/` — legendas genéricas geradas a partir dos ícones usados em cada mapa.

Gerado por `icons.py` / `montar_mestre.py` (pasta `03 - KMZ Obras\_scripts`). Não editar à mão.
